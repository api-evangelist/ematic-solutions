# Ematic Solutions

> Ematic Solutions is a Singapore-headquartered digital marketing and marketing-technology consultancy
> operating across Asia Pacific, backed by 500 Global. Alongside the consultancy it runs its own
> marketing platform — Hi-iQ (list targeting), Bye-iQ (exit-intent subscription overlays) and Retry-iQ
> (cart-abandonment retargeting) — and publishes a small public developer surface: the Ematic.js
> browser tracker, e-commerce plugins for Magento, Shopify, Haravan and PrestaShop, and a RESTful
> Core API (labelled beta) for product-event logging and ESP list subscription management.

Generated by API Evangelist from Ematic Solutions' public knowledge base. Ematic publishes no llms.txt
of its own (https://www.ematicsolutions.com/llms.txt returned 404).

## Core API

Base URL is derived from your own API key — there is no single global host:

    https://<suffix>-api.ematicsolutions.com:8084/v2

The Ematic API key has the form `<hash>-<suffix>`; the suffix names the data center (for example
`sg1`). Note the non-standard port 8084.

Authentication is one header carrying two keys:

    Authorization: ematic-apikey=<ematic-key>,esp-apikey=<esp-key>

JSON only, in and out. At least one of `uuid` or `email` must identify the user on every request.

Published operations:

- `logBrowse` — POST /log/browse — log a product page view
- `logCart` — POST /log/cart — log a full snapshot of the cart
- `logCheckout` — POST /log/checkout — log that checkout was opened
- `logConversion` — POST /log/conversion — log a completed order
- `logBatchMode` — POST /log/batch — submit multiple events at once
- `createSubscription` — POST /subscribe — add an address to the connected ESP list
- `cancelSubscription` — DELETE /subscribe — remove an address from the connected ESP list

Subscribing or unsubscribing an address without the user's consent is prohibited by Ematic's own
developer guide.

## Client libraries

- Ematic.js — https://api.ematicsolutions.com/v1/ematic.min.js — browser tracker, CDN-distributed and
  unpinned; the asset's Last-Modified is 2021-02-18. There is no npm/PyPI/RubyGems/Packagist package
  and no server-side SDK in any language.
- E-commerce plugins for Magento 1.x, Magento 2.x, Shopify, Haravan, Haravan VN and PrestaShop 1.6.x,
  installed from the knowledge base rather than from a marketplace listing.

## What Ematic does not publish

- No OpenAPI, Swagger, AsyncAPI or GraphQL document (probed on every host; all 404)
- No webhooks or event-push surface
- No MCP server and no A2A agent card
- No /.well-known/ documents of any kind — security.txt, OIDC, OAuth metadata and api-catalog all 404
  on www, api, kb and platform hosts
- No status page, changelog, deprecation policy or SLA
- No published rate limits and no 429 in the documented status set
- No pricing page or self-serve signup — API keys are issued when Ematic creates a client account
